# Credit Risk Scoring

## Project Overview

The objective of this project is to build a credit scoring model capable of estimating the probability that a borrower will default on a loan.

The model is designed to use information available at the time of the loan application.

## Business Problem

Credit institutions need to evaluate the risk associated with a borrower before granting a loan.

The objective is to estimate:

P(Default = 1 | Borrower characteristics)

and use this probability to support lending decisions.
